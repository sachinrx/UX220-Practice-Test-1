Typesetting and Web Design

Old Fashioned Typesetting

Old fashioned typesetting involved arranging letters and text manually for printing. Making changes could take a lot of time because the layout had to be adjusted by hand.

Desktop Publishing

Desktop publishing moved this process onto computers. It made it easier to arrange text, images, and page layouts before printing and allowed changes to be made much faster.

HTML and CSS

HTML and CSS are used to create content for the web. HTML provides the structure of a webpage while CSS controls its appearance. Unlike traditional typesetting, web content can also be changed and displayed on different screen sizes.

HTML and CSS are used for web publishing.
